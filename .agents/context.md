# Context

- The repo is public: no secrets, personal paths, hostnames, usernames or work emails in code, docs or commits. Values for one machine live in local files the tools read, never in the repo.
- Each top-level folder is one independent tool with its own README and installer. A change stays inside its folder, apart from that tool's line in the repo README.
